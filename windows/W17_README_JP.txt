W17 - 学校業務・架空通知GUIテスト（本番運用不可）
==============================================

このフォルダは実在の学校、職員、生徒、メールを扱いません。
IT管理者が許可したWindowsテスト端末・サインイン済みのデスクトップのみ使用してください。

1. ZIPを許可済みのローカルフォルダに展開してください。
2. 「00_START_UAT.cmd」をダブルクリックしてください。
   EXEのSHA-256を検証します。異なる場合は起動しません。
   ※SHA-256は改ざん検知の助けですが、デジタル署名や発行元証明ではありません。
3. 同意ダイアログを確認して「続行」を選択してください。中止時にはテストDBを作成しません。
4. 架空の通知2件のうち、1件を「確認済み」、もう1件を「30分後に再表示」にしてください。
5. 画面を閉じて、日本語の読みやすさ・音・GUI操作の質問に実際の結果を回答してください。
6. ユーザーTEMP内の EDU_W8_Synthetic_UAT_*.json は個人名を含まない自己申告の結果です。
   元の記録は変更せず、IT管理者がローカルで確認してください。
7. W23: 画面テストが終わると、同じユーザーTEMP内に
   EDU_W23_Operator_Review_*.json という要約も自動で作成されます。
   最後のダイアログに「Report」と「IT review summary」の2つの保存先が表示されます。
   要約には操作回数、自己申告の日本語表示・通知音・操作結果、
   元の架空テストレポートのSHA-256だけが入ります。
   本物の学校情報やメール本文は入れません。
8. IT担当者へ共有する場合は、組織で許可された手順で、要約と元レポートの
   整合性を確認してください。要約が完成しても独立したGUI確認や
   IT承認・本番承認にはなりません。自動送信もしません。

注意: GitHub self-hosted runner MRCAOはSession 0であり、実際のデスクトップはSession 1です。
サービス上から画面が見えたと判断しないでください。PowerShell実行ポリシーを変更しないでください。
Windowsログイン時の自動起動、15分間隔のTask Scheduler、Outlook、SMTP、
個人情報・人事データ、本番承認はこのテストに含まれません。
この実行ファイルは未署名であり、ITによる配布許可・コード署名が別途必要です。

テストの完了だけで正式な組織の受入れや人事判断の承認にはなりません。
